# Agent Note: 侧边栏看不出哪些会话正在运行

Status: implemented — 侧边栏复用原来那条会动的线并换成看得清的颜色，运行中的会话不再被折叠

## Problem

用户反馈：「左侧 session 区域我也看不出来哪些 session 正在运行」（2026-10-29）。

取证结论（数据链和渲染都在离屏快照里实测过）：
- 运行状态的数据是对的：不管会话是在 App 里发起的，还是从 App 外面（`ds-agent`、Host API）发起的，都会经由 `api-session/status` 和 `turn/start|end` 推到侧边栏。
- 标记本身几乎看不见：它是行底一条 1.2pt 的薄荷色短线，浅色模式下和背景的对比度只有 1.15:1。左侧 13pt 的圆点槽只给「未读」用，运行中的行是空的。
- 折叠起来的会话完全不显示：每个项目只渲染前 5 条，第 6 条以后的运行会话根本不构建，只剩一个「展开其余 N 个」。

## Decision

1. 运行标记仍是行底那条会动的 `DSHActivityLine`，侧边栏传入新的 `DSHTheme.running` 颜色：浅色模式深青、深色模式亮青，对侧边栏背景的对比度为 5.95:1 和 12.35:1；算上线的 0.72 透明度，渲染图实测浅色约 3.25:1。线的 1.2pt 粗细、长度和动画都不变，转录区里的同一条线颜色不变。
2. 运行中的会话永远不折叠：可见行是前 5 条，加上 5 条以外所有运行中的会话；「展开其余 N 个」的 N 不计入这些会话，「收起至 N 个」显示收起后的条数。只有收起后确实会少显示行时，才出现这个按钮。
3. 侧边栏的行按会话身份渲染，不按位置。

## Alternatives considered

- **左侧静态点 + 行尾「运行中」文字（第一版实现）**：用户看过快照后否决：「这个太复杂了不好看」。
- **左侧呼吸点**：用户否决：「现在不是有个线条的滚动样式吗？为什么重新做一个」。现有的线本身是会动的，问题只是颜色太淡，换色就够了，不该另起一套标记。
- **整组收起时在组头加运行提示**：增加视觉元素；收起分组是用户主动的操作，收起后看不到运行中的会话可以接受。
- **折叠时只在「展开其余 N 个」上加提示**：用户还得点开才能看到是哪个会话在运行，没有解决「一眼看出来」的问题。
- **给所有行加轮询刷新**：数据链已经是推送式的而且是对的，问题出在显示，不在数据。

## Consequences

- 用户在侧边栏里能一眼看出哪些会话正在运行，包括从 App 外面（`ds-agent`、Host API）发起的会话。
- 一个项目里运行中的会话多于 5 条时，折叠后可见的行会超过 5 条。这是有意的：运行中的会话比整齐的折叠更重要。
- 整个分组收起时不提示里面有运行中的会话：收起是用户主动的操作，用户也明确不要额外的文字。
- `Sidebar/AGENTS.md` 的不变量已经按这个实现重写；`scripts/test-design-system.sh` 会检查侧边栏把 `DSHTheme.running` 传给了 `DSHActivityLine`。
- 验证：`DSHSidebarTests` 覆盖折叠规则、收起按钮的文案和显示条件、插入新会话后行身份不乱、对比度，以及线的几何和减弱动态效果；`--unit` 和 `test-design-system.sh` 通过。整套检查、构建和冒烟见 Claude 的最终验收。
