# Agent Note: 悬浮圈改版 —— 白昼浅湖 + 跃身鲸

Status: implemented — 用户评价现版"样式跟动画都不够精致"，并定向："白色背景"、"不要太阳，要鲸鱼跃出海面"、"不够清澈，颜色太深"

## Problem

现悬浮圈（44pt 深海夜色 + 月亮升落）有一批可量化的缺陷，不是审美分歧：

1. **描边形同虚设**。`Color.white.opacity(0.35)` 1pt：实测圆压在白色窗口上时，边缘像素是 `(0.055, 0.114, 0.133)` 纯深色，没有任何分离；压在深色桌面上又是一条硬白线。一个浮在任意背景之上的对象，边缘必须自带对比度。
2. **深色本体在深色桌面上消失**。
3. **每 5 秒有 1.3 秒（26%）天上什么都没有**。月亮弧线只走周期的前 82%，其余时间在遮罩之下。运行指示器出现"完全静止"读作卡死。
4. **月亮不是落进海里，是被直线切掉的**。遮罩写死在 `y=27`，正好是浪谷高度；浪高时月亮在离水面尚远处被平切。
5. **三层浪是同一条波形复制三份**（都是 2.5 个空间周期），只有相位速度不同，没有远近层次。
6. **运行/空闲只靠动不动区分**，定格看一帧完全相同。
7. **面板阴影是死的**。`NSPanel.hasShadow = true` 对逐帧变化的透明内容只按首帧计算且不更新，实拍图里圆的左上有一圈发灰死边。
8. **零交互反馈**：可点，但无 hover、无按下态、指针不变手型。
9. **声呐涟漪起手随机**。用绝对时间 `t/1.6` 取模，开始听写那一瞬第一圈从随机半径冒出，且匀速扩散无缓动。

## Decision

### 视觉：白昼浅湖

- 天空近白暖调渐变；三层水改为**真半透明**（0.34 / 0.42 / 0.52），色值整体提亮。关键规则：果冻的"深"必须是层与层**叠出来**的，不是刷上去的——上一稿用 0.92 不透明深青做底层被否，正是踩了这条。参照 `DSHTheme` 自身浅度（`canvas` = 0.961/0.976/0.973）。
- 三层浪给不同空间频率 + 一个二次谐波，分开远近。
- 边缘换双层：内圈自上而下由亮转暗的高光描边（读作"被上方光源照亮的珠子"）+ 外圈 0.5pt 极淡暗线，任何背景都分得开。关掉 `NSPanel.hasShadow`，投影改由 SwiftUI 画。

### 主体：原创跃身鲸

- **不使用 DeepSeek 的鲸鱼标识**。该标识确实可从 app 打包的 runtime 里取到（见 [[dsh-whale-mark-vector]]），也一度做进原型，但它是注册标识，进 app 图标会出现在 Dock 与 GitHub Release 页，容易被读成官方出品。用户明确要求"不要有风险"，故全部重画。
- 构造方式：**圆心链**——给若干「站点」(x, y, 半径)，Catmull-Rom 插值出中轴线与粗细，沿法线偏移成轮廓，头部用整圆封口。头一定是钝圆的，这是"鲸"和"鱼"的分界。尾鳍、口线、眼各自一片。
- 口线（天空色的一道白弧）是让它读成鲸而非鱼的关键一笔；眼在 44pt 下仅 1.2pt，但去掉后小尺寸会退化成深色团块，保留。
- 鲸是画面里唯一的深色 → 焦点唯一，这是"干净"的来源。

### 动画：跃身，无空窗

- 周期 5.5s。`lift = 0.5 - 0.5·cos(2πc)` 抛物线升降；鲸全程可见，最低点半沉、被前两层浪盖住背。
- **翻转角只跟垂直速度走**：`tilt = -22°·sin(2πc)`——上升抬头、顶点放平、下落低头。旧稿把角度接在 `lift` 上，导致顶点仍是抬头的，看着像后仰。
- 水平漂移 `dx = -2.5·cos(2πc)`。三个量都是周期的连续函数，首尾自然衔接（旧原型用 `-3 + 6c` 线性漂移，每圈末尾会闪一下）。
- 空闲态：降饱和 + 鲸半沉停住 —— 定格一帧也能一眼看出在不在跑。
- 听写水纹（原"声呐涟漪"）：用户要"淡淡的水波纹 + 一点阴影扩散"。每圈三层——暗色伴影（浅底上垫厚度）/ 柔光带（扩散感，任何背景都在）/ 细亮线（水纹锋面），峰值透明度全部压到 0.2 以下（旧版是 0.60 的实心 1.5pt 环，读作雷达 ping）。五圈延迟入场，开始的第一瞬只有一圈且贴在圆边；衰减用 1.6 次方而非线性。最大缩放 0.88 是硬上限——44 × 1.88 = 82.7pt 刚好收在 84pt 画布内，再大就会被裁。
- 红点：弹簧弹出 + 一次性光晕。

### 交互

指针变手型；悬停放大 1.06、描边提亮；按下缩到 0.94。

### 落地位置

新文件 `macos/DSHApp/NativeSeaArt.swift` 收口全部形状与配色（`SeaArt` / `WhaleBody` / `WhaleFluke` / `WhaleMouth` / `WhaleMark` / `SeaWhaleScene`）。`WaveBand` 留在 `ConversationView.swift`，补了 `freq` / `harmonic` 两个带默认值的参数，旧调用点不受影响。

### 同步范围

配色与图形常量三处共用，一起改：悬浮圈、转录尾部运行指示器（`ConversationView.swift` 的 `WaveIconArt`）、`scripts/generate-app-icon.swift`。图标不是把 44pt 构图直接放大——水位与鲸的比例单独调。

## Alternatives considered

- **按下态缩放反馈（scaleEffect 0.94）**：写完又退掉了。SwiftUI 的 `DragGesture` / `onLongPressGesture` 都会消费 mouseDown，而悬浮圈拖动靠的是 `isMovableByWindowBackground`——那是 NSWindow 在 `sendEvent` 里截 mouseDown 实现的，被手势吃掉就拖不动了。悬停反馈改用 `onHover`（不消费事件）。要按下态得走 NSEvent 监听，等确认拖动无碍再说。

- **保留深色版作为跟随系统外观的一档**：两套配色要两套调校成本，且这颗圈本该在任何背景上长一个样、被一眼认出；两套反而削弱识别度。放弃。
- **沿用 DeepSeek 鲸鱼标识**：识别度最高、零绘制成本，但有商标误读风险（见上）。用户明确否决。
- **太阳/月亮而非鲸鱼**：做过白底橙日方案，用户否决——鲸鱼是这个产品语境里更贴切的符号。
- **贝塞尔手绘鲸鱼轮廓**：盲调控制点命中率极低（连续三轮产出"蝌蚪""肉团""鱼"），改用圆心链参数化构造后一轮到位。方法本身不是问题，缺的是可调的比例参数。
- **保留胸鳍与背驼峰**：22pt 下胸鳍变成与身体断开的碎片，驼峰把背线变成疙瘩。去掉。
- **水面白沫（浪顶描白线）**：能强化"清澈"，但用户明确要求"不要白沫，要高级干净"。放弃。
- **静止态继续跑 TimelineView 只画同一帧**：白白吃 30fps 重绘，沿用现有做法——静止就渲染普通视图。

## Consequences

- 三处图形同步完成：悬浮圈、转录尾部指示器、App 图标（`AppIcon.icns` 已重新生成）。图标生成器是**手抄一份** AppKit 实现，改 `NativeSeaArt.swift` 的常量时必须同步改它，两边文件头都写了这条。
- 图标生成器里二次贝塞尔要手工升阶成三次（`C1 = P0 + 2/3(Q−P0)`），把两个控制点都填成 Q 会画出另一条曲线——第一版就是这么错的，尾鳍和 app 里对不上。
- `WaveBand` 的采样从 24 段提到 48 段（二次谐波需要），转录指示器一并变细腻。

## Acceptance criteria

- 一个动画周期内不存在"主体不可见"的帧；周期首尾无跳变。
- 悬浮圈压在白窗 / 深色桌面 / 彩色壁纸 / 浅灰面板四种背景上，轮廓都能分离。
- 运行态与空闲态**单帧可辨**（不依赖是否在动）。
- `./scripts/test-macos-native.sh` 与 `--smoke` 全过；`main.swift` 行数不增。

## Risks

- 图形常量三处共用，漏改一处会出现品牌不一致（转录里还是夜色、悬浮圈已是白昼）。收尾时逐处核对。
- 圆心链构造是逐点采样成折线，采样过疏会在大尺寸（1024 图标）露出棱边。图标渲染时提高采样数。
