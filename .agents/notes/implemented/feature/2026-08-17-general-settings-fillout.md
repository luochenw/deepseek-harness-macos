# Agent Note: 通用设置补齐 —— 悬浮圈/通知/回车发送

Status: implemented — 通用页三组开关上线，preset 选择归预设页

## Problem

设置 → 通用 里只有一个"默认 Agent preset"选择器，与「Agent 预设」页
完全重复；真正属于"通用"的原生行为开关一个都没有：

- 悬浮圈只能靠应用菜单 ⌥⌘Y 开关，设置里找不到；
- 回合完成 / 审批提问的系统通知无法关闭；
- 回车发送是硬编码，没有"回车换行、⌘回车发送"的选项。

## Decision

- 通用页移除了默认 preset 选择器（职责归「Agent 预设」页），现为三组：
  1. **窗口**：显示悬浮圈（与 ⌥⌘Y 同一状态，FloatingBubbleManager）；
  2. **通知**：回合完成横幅、审批/提问提醒各自可关（默认开）——只
     控制横幅弹出，菜单栏状态图标照常反映实时状态；
  3. **输入**：回车发送（默认开）；关闭后回车插入换行，⌘回车发送，
     Shift+回车始终换行。
- 偏好键集中在 `AppPrefs` 枚举（新文件 DSHAppPrefs.swift），默认值语义
  "未写过 = 开"，与 @AppStorage 默认参数保持一致。

## Alternatives considered

- **把通知/输入偏好写进 Host 的 settings.yaml**：这些是纯客户端 UI 行为，
  跟 Host 配置生命周期无关；UserDefaults 即可，避免碰配置协议。
- **通用页保留 preset 选择器**：与预设页重复展示同一状态，两处入口
  让"改了哪个生效"变得含糊，删掉更清楚。
- **悬浮圈开关继续只留菜单项**：用户明确找不到（"设置怎么没了"），
  设置页是发现性更好的家；菜单快捷键保留作为快速通道。

## Consequences

- 通用页三组开关即时生效：悬浮圈立即显隐（与 ⌥⌘Y 同一状态）、关通知
  后不再弹横幅、关回车发送后回车换行且 ⌘回车可发。
- 通知开关只挡横幅不挡菜单栏状态图标——若用户预期"全静默"需再细分。
- 同批次：语音无语音等待窗 8s → 5s（用户指定）。
